# Disclaimer

**Experimental. Not advice. Not Kaspa core. Not a KIP.**

This repository sells nothing. There is no vendor, no seat, and no integration contract here. Proof of work is public infrastructure, maintained by miners and by the people who write the software. The subject is where that infrastructure still moves. The network name belongs in a source citation, not in a pitch.

A row that names a company is a public-engineering note. It is not an offer to that company and not a claim that the company uses Kaspa. This repository is a study. A fit on a page is a reading of public files. It is not a deployment and not a result. Kaspa Dollar is someone else's published design. This repository does not raise funds for it and does not ask anyone to send KAS.

A GitHub release, an open pull, and a fundraiser are different facts. Open the link. The live rule is a merged Active KIP, or a KCC file whose header says Final. DAGKnight, vProgs, and Kaspa Dollar are not live.

Laws still apply to SpaceX, Tesla, and anyone who builds on this rail. A public chain does not cancel a license, a sanction, an export rule, or a court order served on a company. Do not put export-controlled data, medical data, or vehicle traces on a public network.

Pay with a QR code, a `kaspa:` URI, or a pasted txid. Never a seed.

The code under `code/` builds an 81-byte payload and the version-1 payload digest. It is not a node and not a wallet. The hash tests compare published vectors from rusty-kaspa v2.1.0. They do not submit a transaction. The SilverScript file was compiled with the v1.0.0 tag of `silverc`. That compile is not a mainnet inclusion, and it is not an execution of `release`.
