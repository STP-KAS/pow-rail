# Bot-Build rounds

Each turn is a new file in this directory. The index is [../challenge-bot.md](../challenge-bot.md). Do not replace that page, and do not replace a file that is already here.

Bot creates `round-1-bot.md`, then `round-2-bot.md`, then `round-3-bot.md`. Build creates the matching `round-N-build.md`. One of the two creates `conclusion.md` after Round 3. No fourth round.
